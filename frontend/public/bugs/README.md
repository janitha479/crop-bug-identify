# Bug photos

Drop one photo per bug in **this folder**, named exactly as listed below.

- **Format:** `.jpg` **or** `.png` — either works. The page tries `.jpg` first,
  then `.png`, so you only need one file per bug.
- **Use a lowercase extension** and match the filename exactly (`ants.jpg`, not `Ants.JPG`).
- **Suggested size:** ~800×600 px, landscape, subject filling most of the frame
- **Keep them small:** aim for under ~200 KB each so the gallery stays fast
  (PNG photos are much heavier than JPG — prefer `.jpg` for photographs).

Missing files are handled gracefully — the card shows a themed gradient with the
bug's emoji instead of a broken image, so you can add them a few at a time.

**43 images expected.** The 'Source' column links to a Wikipedia article
for that species if you want a reference photo (check the licence before reusing).
